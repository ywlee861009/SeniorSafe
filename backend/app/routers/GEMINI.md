# Routers 지침

## 🛣 엔드포인트 설계
- RESTful 원칙을 따르며 명확한 자원 이름을 사용합니다 (예: `/devices`, `/pairings`).
- 각 라우터 파일은 특정 도메인(Device, User, Pairing 등)에 집중해야 합니다.

## 📥 요청 및 응답
- 모든 요청 바디와 응답 바디는 Pydantic 스키마(`app/schemas/`)를 통해 정의합니다.
- 성공적인 응답뿐만 아니라 오류 상황에 대해서도 적절한 HTTP 상태 코드와 메시지를 반환합니다.

## 🛡 의존성 및 보안
- 공통적인 로직(인증, DB 세션 등)은 `Depends()`를 사용하여 처리합니다.
- 비즈니스 로직은 라우터에 직접 작성하지 말고 `app/services/`에 위임하십시오.
