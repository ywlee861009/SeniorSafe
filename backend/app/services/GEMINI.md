# Services 지침

## ⚙️ 비즈니스 로직 처리
- 서비스 계층은 비즈니스 규칙을 구현하고 여러 데이터베이스 모델 간의 상호작용을 조율합니다.
- 복잡한 쿼리나 트랜잭션 처리는 여기서 수행되어야 합니다.

## 💾 데이터베이스 상호작용
- 서비스 함수는 일반적으로 첫 번째 인자로 `db: Session`을 받습니다.
- 데이터베이스 모델(`app/models/`)을 사용하여 데이터를 조작하고 결과를 반환합니다.

## 🔗 외부 서비스 연동
- Firebase(FCM), 외부 API 호출 등의 로직은 전용 서비스 클래스(예: `FCMService`)를 통해 캡슐화합니다.
