# 보호자(Guardian) UI 설계

## 설계 원칙

- **정보 중심**: 연결된 어르신 상태와 낙상 이력을 빠르게 파악
- **표준 Material 3 UX**: 일반 성인 대상, 익숙한 패턴 사용
- **탭 2개로 전체 커버**: 더 이상의 뎁스 없음
- **알림 우선**: 낙상 발생 시 FCM 알림 → 앱 열면 즉시 해당 내용으로

| 낙상 알림 강조 | `#CC0000` | 빨강 |

## 타이포그래피

Material 3 기본 스케일 사용 (별도 커스텀 없음)

| 용도 | 크기 |
|------|------|
| 화면 제목 | 20sp Bold |
| 카드 제목 | 16sp Medium |
| 본문 | 14sp Regular |
| 보조 | 12sp Regular |
| 버튼 | 14sp Medium |

---

## 네비게이션 구조

```
[로그인]
   │
   └──▶ [바텀 탭]
              ├── [탭1: 내 어르신]
              │       └──▶ [낙상 이력]   (← 뒤로가기)
              │       └──▶ [어르신 연결]  (← 뒤로가기)
              │
              └── [탭2: 알림 내역]
```

뎁스: **최대 2단계**

### 3. 탭1 — 내 어르신

> 연결된 어르신 목록. 각 카드에 현재 상태 표시.

```
┌──────────────────────────────┐
│  SeniorSafe            🔔    │  ← 상단바
├──────────────────────────────┤
│  내 어르신                    │  ← 20sp Bold
│                              │
│  ┌────────────────────────┐  │
│  │  👤  홍길동             │  │  ← 카드
│  │      🟢 보호 중         │  │
│  │      마지막 낙상: 없음   │  │
│  │                   ›    │  │  ← 탭하면 낙상 이력
│  └────────────────────────┘  │
│                              │
│  ┌────────────────────────┐  │
│  │  👤  이영희             │  │
│  │      ⚫ 서비스 꺼짐      │  │
│  │      마지막 낙상: 2일 전 │  │
│  │                   ›    │  │
│  └────────────────────────┘  │
│                              │
│  ┌────────────────────────┐  │
│  │   +  어르신 연결하기    │  │  ← 외곽선 버튼
│  └────────────────────────┘  │
│                              │
├──────────────────────────────┤
│    [내 어르신]    [알림 내역] │  ← 바텀 탭
└──────────────────────────────┘
```

**카드 상태 표시**

| 상태 | 아이콘 | 텍스트 |
|------|--------|--------|
| 서비스 ON | 🟢 | 보호 중 |
| 서비스 OFF | ⚫ | 서비스 꺼짐 |

---

### 4. 낙상 이력 (탭1 → 카드 탭)

```
┌──────────────────────────────┐
│  ←  홍길동님 낙상 이력         │
├──────────────────────────────┤
│                              │
│  ┌────────────────────────┐  │
│  │  🔴  2026.05.14        │  │  ← 보호자 알림 발송됨
│  │      오후 3:22          │  │
│  │      알림 전송됨         │  │
│  └────────────────────────┘  │
│                              │
│  ┌────────────────────────┐  │
│  │  ⚪  2026.05.10        │  │  ← 본인이 취소
│  │      오전 11:05         │  │
│  │      본인 취소           │  │
│  └────────────────────────┘  │
│                              │
│  ┌────────────────────────┐  │
│  │  🔴  2026.04.28        │  │
│  │      오후 7:41          │  │
│  │      알림 전송됨         │  │
│  └────────────────────────┘  │
│                              │
└──────────────────────────────┘
```

**이력 타입**

| 타입 | 아이콘 | 설명 |
|------|--------|------|
| 알림 전송 | 🔴 | 보호자에게 실제 알림이 간 낙상 |
| 본인 취소 | ⚪ | 어르신이 직접 오감지 취소 |

---

### 7. FCM 푸시 알림 (앱 외부)

앱이 꺼져 있을 때 수신되는 알림 형태:

```
┌──────────────────────────────┐
│  SeniorSafe                  │
│  🔴 홍길동님 낙상 감지         │
│  지금 바로 확인하세요           │
│  오후 3:22                   │
└──────────────────────────────┘
```

탭하면 앱 실행 → **알림 내역 탭** 으로 바로 이동
