# 보호자(Guardian) UI 설계

## 설계 원칙

- **정보 중심**: 연결된 어르신의 마지막 휴대폰 사용 시각을 빠르게 파악
- **표준 Material 3 UX**: 일반 성인 대상, 익숙한 목록/상세/알림 패턴 사용
- **알림 우선**: 미사용 FCM 알림을 탭하면 해당 어르신 상세로 이동
- **단정 금지**: 위험 상황이라고 확정하지 않고 "사용 기록이 확인되지 않음"으로 표현

## 네비게이션 구조

```text
[역할 선택 / 보호자 등록]
   │
   └──▶ [바텀 탭]
              ├── [탭1: 내 어르신]
              │       ├──▶ [어르신 상세]
              │       └──▶ [어르신 연결]
              │
              └── [탭2: 알림 내역]
```

뎁스: 최대 2단계

## 화면 명세

### 1. 보호자 등록

```text
┌──────────────────────────────┐
│  SeniorSafe                  │
│  보호자 모드                  │
│                              │
│   ┌──────────────────────┐   │
│   │  보호자 이름           │   │
│   └──────────────────────┘   │
│                              │
│   ┌──────────────────────┐   │
│   │      시작하기          │   │
│   └──────────────────────┘   │
└──────────────────────────────┘
```

동작: device 등록 성공 후 `device_access_token` 저장.

### 2. 내 어르신

```text
┌──────────────────────────────┐
│  SeniorSafe            🔔    │
├──────────────────────────────┤
│  내 어르신                    │
│                              │
│  ┌────────────────────────┐  │
│  │  👤  홍길동             │  │
│  │      🟢 오늘 오전 8:30 사용 │
│  │      알림 기준: 2일 미사용 │
│  │                   ›    │
│  └────────────────────────┘  │
│                              │
│  ┌────────────────────────┐  │
│  │  👤  이영희             │  │
│  │      🟠 2일 동안 사용 기록 없음 │
│  │      안부 확인 필요 가능 │
│  │                   ›    │
│  └────────────────────────┘  │
│                              │
│  ┌────────────────────────┐  │
│  │   +  어르신 연결하기    │
│  └────────────────────────┘  │
├──────────────────────────────┤
│    [내 어르신]    [알림 내역] │
└──────────────────────────────┘
```

카드 상태:

| 상태 | 아이콘 | 텍스트 |
|------|--------|--------|
| 최근 사용 확인 | 🟢 | 오늘/어제/날짜 사용 |
| 기준 경과 | 🟠 | N일 동안 사용 기록 없음 |
| 정보 없음 | ⚫ | 아직 사용 기록 없음 |

### 3. 어르신 상세

```text
┌──────────────────────────────┐
│  ←  홍길동님                  │
├──────────────────────────────┤
│  마지막 휴대폰 사용            │
│  오늘 오전 8:30                │
│                              │
│  알림 기준                    │
│  2일 동안 사용 기록 없음        │
│                              │
│  최근 잠금해제 기록             │
│  ┌────────────────────────┐  │
│  │ 오늘 오전 8:30          │  │
│  │ 어제 오후 9:12          │  │
│  │ 어제 오전 7:58          │  │
│  └────────────────────────┘  │
│                              │
│  서비스 실행 내역              │
│  최근 heartbeat: 1분 전        │
│                              │
│  ┌────────────────────────┐  │
│  │      연결 해제          │  │
│  └────────────────────────┘  │
└──────────────────────────────┘
```

### 4. 어르신 연결

```text
┌──────────────────────────────┐
│  ←  어르신 연결하기            │
├──────────────────────────────┤
│   어르신 앱에서 발급한          │
│   6자리 코드를 입력해주세요     │
│                              │
│   ┌──────────────────────┐   │
│   │   _ _ _ _ _ _        │   │
│   └──────────────────────┘   │
│                              │
│   ┌──────────────────────┐   │
│   │       연결하기         │   │
│   └──────────────────────┘   │
└──────────────────────────────┘
```

### 5. 알림 내역

```text
┌──────────────────────────────┐
│  SeniorSafe            🔔    │
├──────────────────────────────┤
│  알림 내역                    │
│                              │
│  ┌────────────────────────┐  │
│  │  🟠  홍길동님           │  │
│  │      2일 동안 사용 기록 없음 │
│  │      오늘 오전 9:00     │
│  └────────────────────────┘  │
│                              │
│  ─────── 이전 알림 없음 ───── │
├──────────────────────────────┤
│    [내 어르신]    [알림 내역] │
└──────────────────────────────┘
```

### 6. FCM 푸시 알림

```text
┌──────────────────────────────┐
│  SeniorSafe                  │
│  홍길동님 휴대폰 사용 기록 없음 │
│  2일 동안 사용 기록이 확인되지 않았습니다 │
│  오전 9:00                   │
└──────────────────────────────┘
```

탭하면 앱 실행 → 해당 어르신 상세 또는 알림 내역으로 이동.

## 요약

| 화면 | 뎁스 | 주요 액션 |
|------|------|----------|
| 보호자 등록 | 0 | device 등록 |
| 내 어르신 | 1 | 상태 확인 |
| 어르신 상세 | 2 | 활동/알림 이력 확인 |
| 어르신 연결 | 2 | 코드 입력 |
| 알림 내역 | 1 | 미사용 알림 확인 |
