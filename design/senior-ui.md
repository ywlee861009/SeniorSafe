# 어르신(Senior) UI 설계

## 설계 원칙

- **화면 수 최소화**: 뎁스 1단계 이내, 뒤로가기 거의 없음
- **텍스트 크기**: 최소 20sp, 주요 요소 28sp 이상
- **터치 영역**: 최소 64dp (Material 기본 48dp보다 크게)
- **고대비**: 배경 흰색 / 텍스트 검정 기준, 중요 상태는 색상으로 추가 강조
- **한 화면 한 행동**: 화면마다 핵심 액션 1개

---

## 색상

| 용도 | 색상 | 비고 |
|------|------|------|
| 배경 | `#FFFFFF` | 순백 |
| 주요 텍스트 | `#111111` | 거의 검정 |
| 보조 텍스트 | `#555555` | |
| 활성 상태 (보호중) | `#1A8A1A` | 진한 초록 |
| 비활성 상태 | `#888888` | 회색 |
| 위험 / 낙상 감지 | `#CC0000` | 진한 빨강 |
| 주요 버튼 배경 | `#1A6FCC` | 파랑 |
| 취소 버튼 배경 | `#CC0000` | 빨강 |

---

## 타이포그래피

| 용도 | 크기 | 굵기 |
|------|------|------|
| 화면 제목 | 26sp | Bold |
| 주요 상태 텍스트 | 28sp | Bold |
| 본문 / 설명 | 20sp | Regular |
| 버튼 레이블 | 22sp | Bold |
| 보조 설명 | 17sp | Regular |

---

## 네비게이션 구조

```
[로그인]
   │
   └──▶ [홈 - 메인]
              │
              └──▶ [연결 코드]   (뒤로가기로 복귀)

※ 낙상 감지 시: 홈 위에 전체화면 오버레이로 표시 (별도 화면 이동 없음)
```

뎁스: **최대 2단계**

## 화면 명세

### 1. 로그인

```
┌──────────────────────────────┐
│                              │
│                              │
│         SeniorSafe           │  ← 앱 이름 (26sp Bold)
│       어르신 안전 서비스        │  ← 20sp
│                              │
│   ┌──────────────────────┐   │
│   │  이메일               │   │  ← 입력창 height 64dp
│   └──────────────────────┘   │
│   ┌──────────────────────┐   │
│   │  비밀번호              │   │
│   └──────────────────────┘   │
│                              │
│   ┌──────────────────────┐   │
│   │        로그인         │   │  ← 높이 72dp, 22sp Bold
│   └──────────────────────┘   │
│                              │
│       처음이신가요? 회원가입    │  ← 20sp 텍스트 버튼
│                              │
└──────────────────────────────┘
```

**동작**: 로그인 성공 → 유저 타입이 `senior`면 홈으로 이동

---

### 2. 회원가입

```
┌──────────────────────────────┐
│  ←                           │
│                              │
│     회원가입                  │  ← 26sp Bold
│                              │
│   ┌──────────────────────┐   │
│   │  이름                 │   │
│   └──────────────────────┘   │
│   ┌──────────────────────┐   │
│   │  전화번호              │   │
│   └──────────────────────┘   │
│   ┌──────────────────────┐   │
│   │  이메일               │   │
│   └──────────────────────┘   │
│   ┌──────────────────────┐   │
│   │  비밀번호              │   │
│   └──────────────────────┘   │
│                              │
│   ┌──────────────────────┐   │
│   │  어르신으로 가입하기    │   │  ← 파랑 버튼 72dp
│   └──────────────────────┘   │
└──────────────────────────────┘
```

---

### 3. 홈 (메인)

> 앱 실행 후 항상 이 화면. 핵심 상태가 한눈에 보여야 함.

```
┌──────────────────────────────┐
│  안녕하세요, 홍길동님           │  ← 20sp
│                              │
│   ┌──────────────────────┐   │
│   │                      │   │
│   │    ●  보호 중         │   │  ← 원형 아이콘 + 28sp Bold
│   │                      │   │     활성: 초록 #1A8A1A
│   │   낙상 감지 서비스     │   │     비활성: 회색 #888888
│   │    실행 중입니다       │   │  ← 20sp
│   │                      │   │
│   └──────────────────────┘   │
│                              │
│   ┌──────────────────────┐   │
│   │    서비스 끄기         │   │  ← 상태에 따라 켜기/끄기 토글
│   └──────────────────────┘   │  ← 높이 72dp
│                              │
│   ┌──────────────────────┐   │
│   │    연결 코드 보기      │   │  ← 높이 64dp, 외곽선 버튼
│   └──────────────────────┘   │
│                              │
└──────────────────────────────┘
```

**상태별 변화**

| 상태 | 원형 색상 | 텍스트 | 버튼 |
|------|----------|--------|------|
| 서비스 ON | `#1A8A1A` 초록 | 보호 중 | "서비스 끄기" |
| 서비스 OFF | `#888888` 회색 | 보호 꺼짐 | "서비스 켜기" |

---

### 4. 낙상 감지 알림 (전체화면 오버레이)

> 홈 화면 위에 겹쳐서 표시. 별도 화면 이동 없음.  
> 배경 빨강(`#CC0000`)으로 전환 → 긴박함 전달.

```
┌──────────────────────────────┐
│                              │
│  ██████████████████████████  │
│  ██                        ██│
│  ██    낙상이 감지되었습니다   ██│  ← 26sp Bold, 흰색
│  ██                        ██│
│  ██████████████████████████  │  ← 배경 전체 #CC0000
│                              │
│                              │
│            [ 25 ]            │  ← 카운트다운 숫자 60sp Bold 흰색
│                              │
│     25초 후 보호자에게         │  ← 20sp 흰색
│       알림을 보냅니다          │
│                              │
│                              │
│   ┌──────────────────────┐   │
│   │   ✋  괜찮아요 (취소)  │   │  ← 높이 80dp, 흰 배경 + 빨간 텍스트
│   └──────────────────────┘   │  ← 22sp Bold
│                              │
└──────────────────────────────┘
```

**동작**
- 카운트다운 0 → 백엔드에 낙상 이벤트 전송
- "괜찮아요" 탭 → 오버레이 닫힘, 이벤트 취소 전송
