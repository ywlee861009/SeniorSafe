# 할일-003 Android 역할 선택 및 페어링 온보딩 구현

## 우선순위

P0

## 문제

현재 Android 앱에는 로그인과 사용자 흐름이 남아 있다. 새 MVP에서는 앱 첫 화면이 로그인 화면이 아니라 보호자/어르신 모드 선택이어야 하며, 연결 코드 기반 페어링을 완료하면 잠금해제 활동 모니터링을 바로 사용할 수 있어야 한다.

## 작업 범위

- 첫 실행 화면을 역할 선택 화면으로 변경한다.
- 어르신 모드:
  - 기기 등록
  - 연결 코드 생성
  - 코드 만료/재생성 UI
  - 보호자 연결 완료 상태 반영
  - 활동 모니터링 서비스 시작 상태 안내
  - 잠금해제 이벤트 기록/업로드 상태 진입점
- 보호자 모드:
  - 기기 등록
  - 연결 코드 입력
  - 실패/만료/이미 사용된 코드 상태 표시
  - 페어링 완료 후 보호자 홈 이동
  - 페어링 완료 후 마지막 잠금해제 시각 조회 준비
- 로그인, 회원가입, 비밀번호 입력 화면을 제거하거나 접근되지 않게 정리한다.
- 역할과 device token을 로컬에 저장한다.
- 앱 재실행 시 기존 페어링 상태로 바로 진입한다.
- 앱 삭제 후 재설치는 새 기기로 취급한다는 동작을 문서화한다.

## 완료 조건

- 새 설치 후 로그인 없이 역할 선택부터 시작한다.
- 어르신 코드 생성과 보호자 코드 입력으로 실제 백엔드 페어링이 완료된다.
- 앱을 다시 열어도 페어링된 홈 화면으로 진입한다.
- 어르신 모드 진입 후 잠금해제 활동 모니터링을 시작할 수 있다.
- 페어링 실패 상태가 사용자에게 명확히 표시된다.
- 기존 로그인 화면이 MVP 진입 흐름에 남아 있지 않다.
