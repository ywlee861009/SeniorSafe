# 할일-004 인증 및 세션 관리 강화

## 우선순위

P1

## 문제

문서와 설정에는 refresh token 만료 시간이 있지만, 실제 인증 응답은 access token만 반환합니다. 로그아웃, 토큰 갱신, 만료된 세션 복구 흐름도 아직 없습니다.

## 작업 범위

- MVP에서 refresh token이 필요한지 결정.
- 필요하다면 refresh token 발급, 저장, 회전, refresh endpoint 구현.
- 필요 없다면 문서와 설정에서 refresh token 항목을 제거하거나 future 항목으로 명확히 표시.
- Android에서 401 응답 처리.
- 로그아웃 및 로컬 토큰 삭제 구현.
- 비밀번호 정책과 인증 에러 메시지 검토.

## 완료 조건

- 세션 정책이 문서, 백엔드, Android에서 일관된다.
- 만료되거나 잘못된 토큰이면 사용자가 자연스럽게 로그인 화면으로 돌아간다.
- 로그아웃 시 로컬 인증 정보가 삭제된다.
- 토큰 만료 또는 refresh 동작이 테스트로 검증된다.
