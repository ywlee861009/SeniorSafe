# 할일-007 보호자 모니터링 기능 보강

## 우선순위

P2

## 문제

보호자 MVP 화면은 있지만 일부 필드는 placeholder에 가깝습니다. `service_active`는 항상 true로 반환되고, 낙상 확인 시간(`acknowledged_at`)은 모델에만 있고 사용되지 않으며, 연결 해제 기능도 없습니다.

## 작업 범위

- 어르신 서비스 활성 상태/heartbeat를 실제로 추적하거나 해당 필드를 제거.
- 필요하다면 낙상 확인 endpoint와 UI 구현.
- 보호자-어르신 연결 해제 플로우 추가.
- 낙상 이력의 날짜 포맷, 빈 상태, 에러 상태, 로딩 상태 개선.
- 알림을 탭했을 때 관련 낙상 상세/이력 화면으로 이동하는 동작 추가.

## 완료 조건

- 보호자 목록에서 가짜 서비스 상태를 보여주지 않는다.
- 보호자가 어르신 연결을 해제할 수 있다.
- 알림 탭 시 관련 앱 화면으로 이동한다.
- 낙상 이력 시간이 사용자 친화적인 로컬 시간 형식으로 표시된다.
