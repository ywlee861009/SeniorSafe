# 할일-007 보호자 모니터링 기능을 페어링 기준으로 보강

## 우선순위

P1

## 문제

보호자 화면은 기존 user 관계와 placeholder 상태에 기대는 부분이 있다. 새 구조에서는 active pairing 기준으로 연결된 어르신, 낙상 이력, 알림 탭 이동, 연결 해제를 제공해야 한다.

## 작업 범위

- 보호자 홈에서 active pairing 목록을 조회한다.
- 어르신 표시 이름과 연결 시간을 보여준다.
- `service_active`가 실제 heartbeat 기반이 아니라면 제거하거나 명확히 숨긴다.
- 필요하다면 senior device heartbeat 또는 last_seen_at을 구현한다.
- 보호자-어르신 연결 해제 플로우를 추가한다.
- 낙상 이력의 날짜 포맷, 빈 상태, 에러 상태, 로딩 상태를 개선한다.
- FCM 알림을 탭했을 때 관련 낙상 이력 또는 상세 화면으로 이동한다.
- 여러 보호자 또는 여러 어르신 연결 범위가 정해졌다면 UI에 반영한다.

## 완료 조건

- 보호자 화면이 user가 아니라 pairing/device 기준 데이터를 보여준다.
- 가짜 서비스 상태를 보여주지 않는다.
- 보호자가 연결을 해제할 수 있다.
- 알림 탭 시 관련 화면으로 이동한다.
- 낙상 이력 시간이 사용자 친화적인 로컬 시간으로 표시된다.
