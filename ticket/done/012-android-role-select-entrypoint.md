# 할일-012 Android 역할 선택 진입점 구현

완료일: 2026-05-18

## 우선순위

P0

## 전제

서버 연동은 하지 않는다. 역할 선택 후 로컬 DataStore에 상태를 저장하고 다음 화면으로 이동한다.

## 문제

현재 앱은 `MVP_DASHBOARD`로 바로 진입한다. 새 MVP에서는 어르신과 보호자가 같은 앱을 설치한 뒤, 첫 화면에서 사용 역할을 선택해야 한다. 로그인, 회원가입, 비밀번호 입력은 첫 흐름에서 제거되어야 한다.

## 작업 범위

- 앱 시작 목적지를 로컬 상태 기준으로 결정한다.
  - 역할 없음: 역할 선택 화면
  - `senior`: 어르신 연결 코드 화면 또는 어르신 홈
  - `guardian`: 보호자 연결 화면 또는 보호자 홈
- `RoleSelectScreen`을 추가한다.
- 화면 문구는 쉬운 표현을 사용한다.
  - 예: `누가 이 휴대폰을 사용하나요?`
  - `어르신이에요`
  - `보호자예요`
- 어르신 선택 시 `localDeviceId`를 보장하고 역할을 저장한 뒤 어르신 연결 코드 화면으로 이동한다.
- 보호자 선택 시 `localDeviceId`를 보장하고 역할을 저장한 뒤 보호자 연결 화면으로 이동한다.
- 기존 로그인/회원가입 화면은 삭제하지 않아도 되지만 MVP 진입 흐름에서는 접근되지 않게 한다.

## 완료 조건

- 새 설치 후 앱 첫 화면이 역할 선택 화면이다.
- 어르신 선택 시 로그인 없이 어르신 플로우로 이동한다.
- 보호자 선택 시 로그인 없이 보호자 플로우로 이동한다.
- 앱 재실행 시 저장된 역할에 따라 역할 선택을 건너뛴다.
- `assembleDebug`가 통과한다.

## 완료 기록

- 앱 시작 목적지를 `DeviceDataStore`의 역할/페어링 상태 기준으로 계산하도록 변경했다.
- `RoleSelectScreen`을 추가하고 `어르신이에요`, `보호자예요` 선택 액션을 로컬 상태 저장과 연결했다.
- MVP 대시보드 직행을 제거했다.
- 어르신은 연결 코드 화면, 보호자는 연결 화면으로 진입한다.
- 검증: `cd android && ./gradlew assembleDebug` 통과.
