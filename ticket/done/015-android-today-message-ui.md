# 할일-015 Android 오늘의 글 화면 및 로컬 알림 목업

완료일: 2026-05-18

## 우선순위

P1

## 전제

서버 콘텐츠 API는 아직 없다. 오늘의 글은 앱 내 고정 문구 또는 로컬 리스트에서 선택한다. 로컬 알림은 실제 예약까지 구현하되, 서버 동기화는 하지 않는다.

## 문제

어르신 앱 재방문을 유도하려면 안전 기능만 보여주는 것보다 매일 열어볼 이유가 필요하다. MVP에서는 종교색을 강제하지 않는 `오늘의 글`을 기본 콘텐츠로 둔다.

## 작업 범위

- `오늘의 글` 화면을 추가한다.
- 어르신 홈에서 오늘의 글 화면으로 이동할 수 있게 한다.
- 로컬 고정 문구 목록을 만든다.
- 오늘 날짜 기준으로 하나의 글을 선택해 표시한다.
- 매일 저녁 8시 로컬 알림 예약 구조를 만든다.
- 알림 문구는 안전을 단정하지 않고 앱 재방문 유도에 집중한다.
  - 예: `오늘의 글이 도착했어요`
- 알림 탭 시 오늘의 글 화면으로 이동하도록 준비한다.
- 오늘의 글 열람 시각을 로컬 이벤트로 기록할 수 있게 한다.

## 완료 조건

- 어르신 홈에서 오늘의 글 화면으로 이동할 수 있다.
- 오늘 날짜에 맞는 글이 표시된다.
- 로컬 알림 예약 코드가 존재한다.
- 알림 탭 이동 경로가 정의된다.
- 서버 없이도 화면과 기본 동작을 확인할 수 있다.
- `assembleDebug`가 통과한다.

## 완료 기록

- `TodayMessageScreen`을 추가하고 어르신 홈에서 이동하도록 연결했다.
- `TodayMessageProvider`가 오늘 날짜 기준으로 로컬 고정 문구를 선택한다.
- 매일 저녁 8시 `AlarmManager.setInexactRepeating()`으로 로컬 알림을 예약하는 `TodayMessageNotificationScheduler`를 추가했다.
- `TodayMessageNotificationReceiver`를 추가해 `오늘의 글이 도착했어요` 알림과 오늘의 글 route 이동 extra를 구성했다.
- 오늘의 글 화면 열람 시 `ActivityRepository.recordServiceEvent()`로 로컬 이벤트를 기록한다.
- 검증: `cd android && ./gradlew assembleDebug` 통과.
