# 할일-013 Android 어르신 연결 코드 목업 UI 구현

완료일: 2026-05-18

## 우선순위

P0

## 전제

서버가 아직 없으므로 실제 페어링 코드는 로컬에서 목업으로 생성한다. 서버 연동 티켓에서 이 목업 생성 로직을 API 호출로 교체한다.

## 문제

어르신은 복잡한 계정 입력 없이 보호자에게 숫자 코드를 알려줄 수 있어야 한다. 현재 `PairingCodeScreen`은 기존 인증 기반 repository에 의존한다.

## 작업 범위

- 어르신용 연결 코드 화면을 새 MVP 문구로 정리한다.
- 6자리 숫자 코드를 로컬에서 생성해 표시한다.
- 코드 표시를 큰 글씨와 넓은 터치 영역 중심으로 만든다.
- 코드 만료 시간 UI를 목업으로 표시한다.
  - 예: `10분 동안 사용할 수 있어요`
- `새 코드 받기` 버튼을 제공한다.
- `보호자와 연결됐어요` 목업 버튼 또는 개발용 액션을 제공한다.
  - 서버 연동 전까지 페어링 완료 상태를 수동으로 저장하기 위한 임시 장치다.
- 연결 완료 처리 후 어르신 홈으로 이동한다.
- 화면에는 `UUID`, `device token`, `server` 같은 기술 용어를 노출하지 않는다.

## 완료 조건

- 어르신 역할 선택 후 연결 코드 화면이 열린다.
- 6자리 코드가 표시된다.
- 새 코드 받기 버튼으로 코드가 바뀐다.
- 목업 연결 완료 액션을 누르면 로컬 페어링 상태가 `paired`가 된다.
- 페어링 완료 후 앱 재실행 시 어르신 홈으로 이동한다.
- `assembleDebug`가 통과한다.

## 완료 기록

- 기존 인증 기반 `PairingRepository` 호출을 제거하고 로컬 6자리 숫자 코드 생성으로 교체했다.
- `새 코드 받기`로 코드가 재생성된다.
- `보호자와 연결됐어요` 개발용 액션으로 로컬 페어링 상태를 `paired`로 저장하고 어르신 홈으로 이동한다.
- 화면에서 UUID, device token, server 같은 기술 용어를 노출하지 않는다.
- 검증: `cd android && ./gradlew assembleDebug` 통과.
