# 완료-001 백엔드 API 테스트 추가

## 우선순위

P0

## 문제

백엔드 핵심 API는 구현되어 있지만 자동화 테스트가 없습니다. 현재는 인증, 페어링 권한, 낙상 이력 접근 제어, FCM 부수 효과에서 회귀가 생겨도 수동 테스트 전까지 알기 어렵습니다.

## 작업 범위

- FastAPI async 엔드포인트용 pytest 환경 추가.
- 테스트 DB 또는 트랜잭션 격리 전략 구성.
- 회원가입, 로그인, 이메일 중복, 잘못된 비밀번호 테스트.
- 어르신 전용 페어링 코드 발급과 보호자 전용 연결 테스트.
- 낙상 보고, 취소, 보호자 이력 조회 권한 테스트.
- 테스트에서는 Firebase 호출을 mock 처리하거나 비활성화.

## 완료 조건

- 백엔드 테스트 실행 명령이 문서화되어 있고 로컬에서 통과한다.
- 보호 엔드포인트의 토큰 없음/잘못된 토큰 케이스를 검증한다.
- 어르신 전용 API와 보호자 전용 API의 역할 제한을 검증한다.
- FCM 실제 전송 없이 테스트가 통과한다.
