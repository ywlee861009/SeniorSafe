# 할일-014 Android 어르신 홈 UI 구현

완료일: 2026-05-18

## 우선순위

P0

## 전제

서버는 아직 없다. 잠금해제 기록은 기존 `core:activity` 로컬 DB를 우선 사용하고, 업로드 상태는 목업 또는 로컬 상태로 표시한다.

## 문제

연결 완료 후 어르신이 보게 될 홈 화면이 필요하다. MVP의 핵심은 낙상 감지가 아니라 휴대폰 사용 기록 기반 안부 확인이므로, 어르신 홈도 “보호 중/낙상”이 아니라 “보호자 연결/휴대폰 사용 기록 확인” 중심이어야 한다.

## 작업 범위

- 새 어르신 홈 화면을 구현하거나 기존 `SeniorHomeScreen`을 새 MVP에 맞게 교체한다.
- 홈 화면 주요 정보:
  - 보호자 연결 완료 상태
  - 활동 모니터링 실행 상태
  - 최근 휴대폰 사용 기록 시각
  - 오늘 기록된 사용 횟수
- 활동 모니터링 시작/중지 버튼을 제공한다.
- 버튼 문구는 쉬운 표현을 사용한다.
  - 예: `사용 기록 확인 켜기`
  - `사용 기록 확인 끄기`
- `오늘의 글 보기` 진입점을 배치한다.
- 낙상 감지 문구와 낙상 이력 중심 UI를 제거하거나 MVP 흐름에서 숨긴다.
- 연결이 끊긴 상태 또는 아직 연결 전 상태로 돌아갈 수 있는 개발용 초기화 동작은 별도 디버그 영역에 둔다.

## 완료 조건

- 페어링 완료 후 어르신 홈이 표시된다.
- 홈에서 활동 모니터링 서비스를 시작/중지할 수 있다.
- 최근 로컬 잠금해제 기록이 화면에 표시된다.
- 낙상 중심 표현이 어르신 MVP 홈에서 보이지 않는다.
- 어르신이 읽기 쉬운 큰 글씨와 단순한 버튼 구조를 사용한다.
- `assembleDebug`가 통과한다.

## 완료 기록

- `SeniorHomeScreen`을 보호자 연결/휴대폰 사용 기록 중심 UI로 교체했다.
- `core:activity`의 `ActivityMonitorController`, `ActivityServiceStateStore`, `ActivityRepository`를 사용해 서비스 실행 상태, 최근 잠금해제 시각, 오늘 사용 기록 수를 표시한다.
- 홈에서 `사용 기록 확인 켜기/끄기`로 활동 모니터링 서비스를 제어한다.
- `오늘의 글 보기` 진입점을 추가했다.
- 개발용 `연결 전으로 돌아가기` 액션은 별도 하단 영역에 배치했다.
- 검증: `cd android && ./gradlew assembleDebug` 통과.
