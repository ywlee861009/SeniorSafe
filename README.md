# SeniorSafe

SeniorSafe는 Android 앱과 FastAPI 백엔드로 구성된 고령자 안부 확인 MVP입니다.

현재 MVP는 낙상 감지 제품화를 보류하고, 어르신 휴대폰이 일정 기간 잠금해제되지 않으면 보호자에게 FCM 푸시를 보내는 흐름에 집중합니다.

핵심 문서:

- `docs/overview.md`: 제품 개요와 현재 MVP 계약
- `docs/api-spec.md`: device/pairing/activity API 명세
- `docs/deployment.md`: Docker 기반 배포 가이드
- `ticket/README.md`: 현재 작업 우선순위
- `design/`: 어르신/보호자 UI 설계
