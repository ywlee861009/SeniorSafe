# Feature 모듈 지침

## 🎯 목적
특정 사용자 화면과 워크플로우를 구현합니다.

## 🏗 구조
- `navigation/`: `NavGraphBuilder` 확장 함수 및 경로 상수 정의.
- `[Feature]Screen.kt`: 화면의 메인 UI 진입점.
- `[Feature]ViewModel.kt`: 화면의 상태 및 로직 관리.

## 🔗 규칙
- **독립성**: 기능 모듈은 서로 의존해서는 안 됩니다.
- **내비게이션**: `app` 모듈에서 콜백을 통해 기능 간 이동을 조율합니다.
- **데이터 접근**: 오직 `core:data` 저장소를 통해서만 데이터에 접근합니다.
