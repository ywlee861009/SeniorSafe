# Core 모듈 지침

## 🎯 목적
재사용 가능하고 기능 중립적인 컴포넌트와 데이터 계층을 제공합니다.

## 🚫 제약 사항
- **기능 로직 배제**: "Senior" 또는 "Guardian" 흐름에만 특화된 로직을 여기에 포함하지 마십시오.
- **격리**: 각 코어 모듈은 단일하고 명확한 책임을 가져야 합니다.

## 📂 주요 서브 모듈
- `core:model`: 순수 Kotlin 데이터 클래스 (DTO 및 도메인 모델).
- `core:network`: Retrofit 서비스 및 API 구성.
- `core:data`: 저장소(Repository) 및 데이터 동기화 로직.
- `core:ui`: 공통 디자인 시스템, 테마 및 재사용 가능한 UI 컴포넌트.
- `core:util`: 범용 유틸리티 함수.
