# Data 모듈 지침

## 🗄 저장소(Repository) 패턴
- 모든 데이터 접근은 Repository를 거쳐야 합니다.
- Repository는 네트워크 DTO와 도메인 모델 간의 매핑을 처리해야 합니다.
- 구현체는 가급적 `internal`로 유지하고 인터페이스나 Repository 클래스 자체만 노출합니다.

## 🔄 동기화 및 상태
- DataStore나 Room과 같은 로컬 소스에서 반응형 데이터 스트림을 노출할 때는 `Flow`를 사용합니다.
- 네트워크 오류를 우아하게 처리하고 도메인별 결과 또는 예외로 매핑합니다.
